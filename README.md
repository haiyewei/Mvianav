# Mvianav

Mvianav是一个现代化的多引擎搜索工具，让用户可以轻松切换并使用不同的搜索引擎。

## 功能特点

- 支持多种搜索引擎（Google、百度、Bing等）
- 分类管理搜索引擎
- 响应式设计，支持桌面和移动设备
- 平滑动画过渡效果
- 自定义搜索引擎配置

## 技术栈

- Lit Element
- Material Web Components
- Vite构建工具

## 使用方法

1. 点击搜索框，展开引擎选择面板
2. 选择搜索引擎分类
3. 点击所需的搜索引擎
4. 输入搜索内容并按回车进行搜索

## 开发

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建项目
npm run build
```

## 自定义搜索引擎

可以通过编辑`public/search-engines.json`文件来添加或修改搜索引擎。
